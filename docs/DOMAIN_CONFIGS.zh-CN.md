# 十领域基准契约

RW-Cite 从包含 3,144,903 条论文元数据记录的共享语料库自动构建领域基准。
每个领域均独立完成论文检索、全文解析、引文图构建以及训练和测试查询划分。
基准构建不依赖人工相关性标注；论文在引言和相关工作章节中出现的引文用于
形成监督信号和评测标签。

本文档只描述论文中报告并公开发布的十个领域。`configs/domains.yaml` 中的
其他条目仅作为扩展配置示例，不属于公开的十领域基准。

## 自动构建流程

十个领域使用相同流程：

1. 从共享元数据语料生成三级主题表示；
2. 使用领域原型查询检索近期论文；
3. 下载并解析论文源文件；
4. 提取引言及相关工作类章节中的引文；
5. 将被引论文解析为统一标识符并执行被引论文闭包；
6. 清理引文上下文，同时保持图拓扑不变；
7. 筛选合格查询并冻结时间划分；
8. 导出完整抽取图以及用于评分的划分掩码图；
9. 保存查询、候选、标签和来源清单。

完整抽取图用于冻结观测到的引文标签。模型训练和评分使用移除了测试及前沿来源
出边的划分掩码图，因此查询论文的出边只作为标签，不作为推理特征。

## 配置与复现

- `configs/domains.yaml` 保存公开领域标签和产物路径；
- `configs/config_<tag>.yaml` 保存原型查询、检索规模、时间范围和下载目录。

验证领域图：

```bash
python -m rwcite.cli.validate_graph --gexf /path/to/domain_graph.gexf
```

重建已注册领域：

```bash
bash scripts/run_domain_graph_build.sh \
  --domain <tag> --cutover --seed-only
```

发布清单保存图校验和、查询标识符、候选清单和配置。只有在这些标识符满足同一
评测契约时，结果才应被直接比较。

## 扩展到新领域

该自动流程不限于已发布的十个领域。新增领域需要定义原型查询与检索约束、注册
产物路径，并运行相同的图构建与验证流程。新领域应在冻结清单和图统计公开后再与
现有基准结果共同报告。
